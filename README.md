# CRUD Module for Perfex CRM

The CRUD Module is a comprehensive Create, Read, Update, and Delete system designed to efficiently manage and store client information within the Perfex CRM. This module is built using PHP and HTML, leveraging the robust frameworks of Perfex CRM and CodeIgniter 3.

## Key Features
- Seamless integration with Perfex CRM
- Easy client management with intuitive CRUD operations
- Built on the reliable CodeIgniter 3 framework
- Developed using PHP and HTML for maximum compatibility and performance

Enhance your Perfex CRM experience with this powerful CRUD module, ensuring efficient client data management and streamlined operations.
